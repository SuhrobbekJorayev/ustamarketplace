# 🛠 UstaMarketplace

UstaMarketplace — bu xizmat ko‘rsatuvchi ustalar va mijozlar o‘rtasida buyurtma berish tizimi bo‘lgan web platforma.

Loyiha Django REST Framework asosida qurilgan bo‘lib, frontend HTML + Bootstrap + JavaScript orqali ishlaydi.

---

# 🚀 Features

### 👤 User system
- Register / Login (JWT authentication)
- Client va Worker rollari

### 🔧 Services
- Ustalar xizmat qo‘shishi
- Xizmatlar ro‘yxati

### 📦 Orders
- Mijoz xizmat tanlaydi
- Buyurtma yaratadi
- Dashboard orqali kuzatadi

### 📊 Dashboard
- User buyurtmalarini ko‘rish
- Status tracking

---

# 🧱 Tech Stack

### Backend:
- Django 5
- Django REST Framework
- SimpleJWT
- PostgreSQL

### Frontend:
- HTML5
- CSS (Bootstrap 5)
- JavaScript (Vanilla JS)

### DevOps:
- Docker (basic setup)
- Render deployment ready
